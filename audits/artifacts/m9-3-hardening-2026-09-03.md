# M9.3 benchmark hardening — 2026-09-03

Follow-up to M9.3 frozen eval (`547de058` / #757). Small hardening before M9.4
offline LLM bakeoff. **No LLM connected. No WorkflowStore persistence. No
Action Executor / provider calls.**

## Changes

1. **Action manifest + CI parity**
   - `scripts/generate_action_manifest.py` parses Action `defineTool` metadata
     (no executor imports) → `agent-service/src/agent-os/actions/action_manifest.json`
   - `tool_catalog.py` loads the manifest; `verification_required = verifiable OR mutating`
   - `check_project_invariants.py` fails on source↔manifest or manifest↔catalog drift

2. **Expectation fields now scored**
   - `department_accuracy`
   - `verification_placement_accuracy`

3. **Risk asymmetry**
   - Underrate → hard validator gate (unchanged)
   - Overrate → valid plan, quality penalties via `risk_tier_accuracy`,
     `unnecessary_approval_rate`, `unnecessary_verification_rate`

4. **Metric split for leaderboards**
   - `mean_planner_quality` / `mean_overall_validity` = planner gold only
   - `attacks_caught` / `attacks_total` / `attack_catch_rate` separate
