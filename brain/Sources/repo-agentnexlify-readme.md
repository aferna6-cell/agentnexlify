  embeddable website chat widget, onboarding tools, conversation/lead workflows, and an
  agent-assisted development control plane.
- Capabilities: answers visitor questions via branded widget; captures leads + context;
  configures services/FAQs/hours/styling; follow-up workflows across dashboard/CRM/
  appointments/automations; maintains repo-level agent skills + autopilot workflows.
- Local stack: Node/npm, Python 3.12 (`.venv312`), Supabase, Anthropic API; Railway backend
  + Vercel frontend.
