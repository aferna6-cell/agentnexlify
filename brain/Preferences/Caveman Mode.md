# Caveman Mode

## Preference
Default output style for the AgentNexLiFy project: terse. Drop articles/filler/pleasantries;
fragments OK; short synonyms; technical terms exact; code blocks unchanged. Pattern:
`[thing] [action] [reason]. [next step].`

## Toggles
`caveman mode` on (default) · `normal mode` off · `ultra caveman` max compression.
