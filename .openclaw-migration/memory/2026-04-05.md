
## 2026-04-05 — AgentNexLiFy repo audit + hardening sprint
- Repo cloned at `/home/aidan/agentnexlify` and audited deeply for runtime AI surfaces and developer-agent resources.

- Security findings from audit:
  - Critical: tracked `.mcp.json` contained a real Supabase MCP token pattern; removed raw secret pattern later, but token still needs rotation operationally.
  - High: tracked Claude hooks auto-run repo-local shell scripts; command logging can persist pasted secrets.
  - Medium: local permissions allowed broad `.env` reads; stop-hook auto-commit risk.
- Runtime AI findings:
  - Widget AI prompt path was centralized-ish but had prompt-injection exposure from crawled site text, corrections, KB, and custom instructions.
  - Model output could trigger side effects through `HANDOFF_REQUESTED`, `<!--ORDER_JSON:...-->`, and `<!--BID_REQUEST:...-->`.
  - `mcp_server.py` was accepting widget API keys for MCP auth; later tightened.
  - Embeddings existed but were not the hot path for widget retrieval.
