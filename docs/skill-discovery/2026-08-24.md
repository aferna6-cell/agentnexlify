### 1. `dependabot-merge-runner`

**Status:** Third consecutive week of evidence. Subconscious run 108 validated it as high-confidence and mandate-triggered. Escalate to implementation priority.

**Trigger condition:**  
Nightly commit review (or manual invocation) finds 3+ Dependabot PRs open for 5+ days.

**Steps it would automate:**
1. List open PRs via `mcp__github__list_pull_requests`, filter to `user.login == "dependabot[bot]"`
2. For each: read `mergeable_state` — skip if not `"clean"`

### 3. `blocker-escalation-commenter`

**Status:** New proposal this week. Pattern emerged from two consecutive subconscious runs.

**Trigger condition:**  
A GitHub issue tagged `human-action-required` or `critical` has been open for 30+ days with no update to the blocked state.

**Steps it would automate:**
1. List issues with labels `human-action-required` or `critical` via `mcp__github__list_issues`
2. For each, read last comment timestamp — skip if a targeted escalation comment was posted in the last 7 days
3. Construct a targeted escalation comment: current age, exact 3–5 step remediation path (from issue body or knowledge-base), opportunity-cost statement (days blocked × estimated value)
4. Post comment via `mcp__github__add_issue_comment`
5. Log posted issue numbers to nightly report

**Evidence:**
- `subconscious/runs/2026-08-19/winning-concept.md` — Bonus Action: "post targeted comment on GH #403 with exact ANTHROPIC_API_KEY Railway path" (5 steps, estimated 2-min ROI for human)
- `subconscious/runs/2026-08-20/winning-concept.md` — Bonus Action: "post diagnostic comment on GH #403 with ALL required GH Actions secrets (ANTHROPIC_API_KEY + SUPABASE_URL + SUPABASE_ANON_KEY)"
- Both runs executed this bonus action on the same issue (#403), confirming the pattern recurs
- GH #399 has also received multiple escalation comments from prior subconscious runs (runs 96/97/98 noted in ideas.md)
- Pattern: blocker open N days → system generates exact-path fix comment → posts to issue — then repeats next week

**Why a skill:** The bonus-action pattern is ad hoc today; each subconscious run re-derives the comment content from scratch. A skill would centralize the logic, read the issue body to extract known remediation steps, and avoid duplicate escalation comments.

**Estimated time saved:** 5 min per blocker per week of manual discovery + drafting. High-leverage if it finally unblocks GH #403 / #399.
