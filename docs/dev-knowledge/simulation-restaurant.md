# Customer Simulation: Restaurant
Date: 2026-03-22

## Persona
Tony Rossi, owns a family Italian restaurant. 30 seats, 2 servers, 1 chef. Active on Instagram with food photos. Pain points: managing takeout/delivery orders via phone, last-minute catering requests, no-show reservations, getting more Google reviews.

## Journey (Using Industry-Content Skill Checklist)

### 1. FAQs ✓ (4 FAQs)
Hours, delivery, reservations, catering. Adequate but could add: allergens, private events, gift cards.

### 2. Pipeline Preset ✓
Inquiry → Reservation → Catering Quoted → Booked → Cancelled. Good for catering pipeline.

### 3. Form Preset ✗ Missing
No catering/event inquiry form. Restaurants need: event date, guest count, budget, dietary restrictions.

### 4. Reminders ✗ Missing
No restaurant-specific reminder extras. Could add: "Menu available online at our website."

### 5. Aftercare ✗ Missing
No restaurant aftercare. Could add: "Thank you for dining with us! Leave a review."

### 6. Rebook ✗ Not applicable
Restaurants don't typically rebook on a fixed interval.

### 7. Menu + Orders ✓ (Full Module)
Menu management, auto-import from website, order-taking via chat, order notifications. This is strong.

### 8. Widget ✓
Menu panel in widget, order confirmation, booking. Very functional.

## Gaps Found
1. **No catering inquiry form** — Restaurants need event date, guest count, budget, dietary restrictions
2. **No restaurant reminder extras** — "Check our menu online" before a reservation
3. **No post-dining aftercare** — Thank you + review request nudge
4. **More FAQs needed** — Allergens, private events, gift cards, parking
5. **No table/reservation management** — Appointments work for time slots but not table assignment

## Strengths
- Full menu management with auto-import from website
- Order-taking via chat widget (the core differentiator)
- Order notifications to owner (SMS + email + webhook)
- Menu display in widget with categories
- Pipeline preset matches catering workflow
- Review requests work after dining

## Verdict
A restaurant owner would pay for this TODAY. The menu + ordering + widget combo is the strongest feature set. The chat widget effectively becomes a digital ordering system. Score: 8/10. Missing: catering form, more FAQs, aftercare message. But the ordering module alone justifies the subscription.
