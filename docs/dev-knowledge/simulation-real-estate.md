# Customer Simulation: Real Estate Agent
Date: 2026-03-21

## Persona
Mike Torres, licensed Realtor. 5 years experience. Handles 15-20 active clients. Uses Zillow Premier Agent + manual follow-up. Pain points: leads go cold if not contacted within 5 minutes, losing track of which properties clients have seen, no centralized transaction tracking.

## Journey
1. **Signup** — "realestate" type selected. 3 generic FAQs auto-generated. Missing: pre-approval, neighborhoods, pricing.
2. **Lead capture** — AI captures name/email/phone. No buyer qualification (budget, timeline, pre-approved?).
3. **Appointments** — Can book showings but no property address field. No travel buffer between showings.
4. **Follow-up** — Generic sequences only. No "post-showing" or "open house" templates.
5. **Documents** — E-signature works but no RE templates (purchase agreement, disclosure).
6. **Pipeline** — Generic stages. RE needs: Contacted → Showing → Offer → Under Contract → Inspection → Close.
7. **Content** — Can generate social posts. No MLS integration for property details.
8. **Analytics** — No conversion funnel (leads → showings → offers → closed).

## Gaps Found (Priority Order)
1. No buyer qualification in AI (budget, timeline, pre-approved) — Added to backlog
2. No RE-specific pipeline stages — Added to backlog
3. No property address in appointments — Added to backlog
4. No post-showing follow-up template — Added to backlog
5. More RE FAQs needed (6 additional)
6. No RE document templates (purchase agreement, disclosure)
7. No showing feedback form
8. No RE-specific analytics (shows-to-offer ratio)

## Strengths
- Document e-signature works (can send contracts today)
- Pipeline is configurable (agent can manually create RE stages)
- Content studio generates listing posts
- Lead scoring + emergency detection works
- SMS/email follow-up automation works

## Verdict
A real estate agent would pay for the product for basic lead capture + appointment booking + document signing. But they'd feel the pipeline stages are wrong, the AI doesn't qualify buyers, and there's no property-level tracking. Quick wins: more RE FAQs, RE pipeline preset, post-showing automation template. Would need property showings feature for long-term retention.
